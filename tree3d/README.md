# 🎄 Ёлка-симулятор 2026 → 2027

Новогодняя 3D-игра-песочница: нарядите ёлку к Новому 2027 году прямо в браузере.

## Возможности

| Инструмент | Что делает |
|---|---|
| 🔴 Шары | Клик по кроне вешает шар (6 цветов или «случайно», до 250 шт.) |
| 💡 Гирлянда | Обматывает ёлку светящейся нитью с «бегущими огнями» (до 8 нитей) |
| ⭐ Звезда | Устанавливает сияющую звезду на макушку с настоящим источником света |
| 🎁 Подарки | Клик по снегу ставит подарочную коробку с лентой и бантом (до 20 шт.) |
| 🎆 Салют | Запускает фейерверк в небо (взрыв со вспышкой, подсвечивающей сцену) |
| 🧹 Убрать | Клик по украшению снимает его |

- **Камера:** тянуть мышью/пальцем — вращение, колесо/щипок — зум, автоповорот до первого касания.
- **«Новогоднее настроение»**: шары +2%, гирлянда +7%, подарки +3%, звезда +10%. На 100% — большой салют и поздравление.
- **Обратный отсчёт** до Нового 2027 года в углу экрана.
- **Музыка и звук:** чиптюн «Jingle Bells» и все эффекты синтезируются через WebAudio (без аудиофайлов).
- **Снегопад**, звёздное небо, луна, снеговик, лес елей, сияющая надпись «2027».
- **Сохранение** прогресса в `localStorage`, скриншот кнопкой 📷.
- **Горячие клавиши:** `1–6` — инструменты, `M` — музыка.

## Запуск

Игра — статика, зависит только от локального файла Three.js (`js/three.module.min.js`, r169), CDN не нужен:

```bash
cd tree3d
python3 server.py            # http://0.0.0.0:8080
# или любой другой статический сервер, например:
# python3 -m http.server 8080
```

Затем открыть <http://localhost:8080>.

### Совсем без сервера

Файл **`single.html`** — вся игра одним файлом (Three.js и код встроены, ~1,3 МБ).
Скачайте его и откройте двойным кликом в любом браузере — работает даже без интернета.

## Технологии

- Three.js r169 (ES-модуль, лежит локально в `js/`)
- Нативный WebGL через Three.js, собственные орбитальные управление камерой (без зависимостей)
- WebAudio — процедурные звуки и музыка
- Всё UI — на русском, мобильные устройства поддерживаются (тач-управление)
