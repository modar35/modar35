# Modar SAMP — лаунчер SA-MP для Android

Лаунчер для **San Andreas Multiplayer**: список серверов с живым онлайном, запуск установленного
SA-MP-клиента сразу с нужным адресом, мод-паки с вашего сервера и новости/обновления.
Нативное Android-приложение на чистом Java — **без AndroidX и сторонних библиотек**;
сервер лаунчера — Node.js **без единой зависимости** (как и Modar Family).

```
samp-launcher/
├── app/                    приложение (Java, framework-API): com.modar.samp
│   └── src/main/java/com/modar/samp/
│       ├── MainActivity.java        список серверов, поиск, фильтры, подключение
│       ├── ServerInfoActivity.java  игроки, правила, карта — всё по SA-MP Query
│       ├── ModsActivity.java        мод-паки: установка, обновление, откат, свой zip
│       ├── NewsActivity.java        новости и обновление лаунчера
│       ├── SettingsActivity.java    сервер лаунчера, клиент, ник, каталоги
│       ├── SampQuery.java           протокол SA-MP Query по UDP (чистый java.net)
│       ├── ClientLauncher.java      поиск клиента и передача ему адреса
│       ├── Api.java                 клиент сервера лаунчера

├── apk/ModarSAMP-1.0.apk   готовый подписанный APK (108 КБ)
├── server/                 сервер лаунчера: API + веб-панель (Node.js)
├── tools/                  сборка APK, тесты ядра, mock-сервер SA-MP
└── docs/preview.html       макет экранов приложения
```

## Что умеет приложение

| Раздел | Возможности |
|---|---|
| 🌐 Серверы | список, добавление по `ip:порт`, избранное, поиск, фильтр «онлайн», кэш последнего ответа |
| 📡 Онлайн | **настоящий опрос SA-MP** по UDP (коды `i`, `r`, `c`, `d`, `p`): игроки, максимум, режим, язык, карта, правила, задержка |
| 🎮 Подключение | находит установленный клиент SA-MP, передаёт ему адрес, порт, ник и пароль через `Intent`; если сборка их не читает — адрес остаётся в буфере обмена |
| 📦 Моды | мод-паки с сервера лаунчера: скачивание с прогрессом, проверка **SHA-256**, распаковка в папку игры, **резервная копия** заменённых файлов, обновление и полный откат, установка своего zip |
| 📰 Новости | новости проекта и обновление самого лаунчера (скачивание APK через DownloadManager) |
| ⚙️ Настройки | адрес сервера лаунчера, каталог игры и каталог лаунчера, клиент и его активити, ник, пароль сервера по умолчанию, **свои имена extras**, таймаут опроса |

Приложение не собирает телеметрию, не содержит рекламы и не ходит никуда, кроме адресов, которые
указали вы. Разрешения: интернет, доступ к файлам (для установки модов в папку игры).

## Как это работает: подключение к серверу

Мобильный SA-MP — это форки одного клиента, и единого стандарта «как снаружи передать адрес»
у них нет. Лаунчер исходит из того, что реально работает, и делает три вещи сразу:

1. **Extras в `Intent`** — самые распространённые имена: `ip`, `port`, `nickname`, `password`
   (плюс синонимы `host`, `port`, `server_ip`, `server_port`, `nick`, `name`, `server_password`).
   Большинство сборок читают именно `ip`/`port` — например, `SAMP.java` в открытых клиентах
   делает `getStringExtra("ip")` и `getIntExtra("port", 7777)`.
2. **Строка аргументов** — `args`/`cmdline` вида `-c -h 1.2.3.4 -p 7777 -n Nick -z Пароль`
   (тот же набор параметров, что у классического `samp.exe`).
3. **Буфер обмена** — `ip:port` копируется всегда: если сборка extras игнорирует, адрес
   вставляется в меню «Добавить сервер» внутри игры долгим нажатием.

Имена extras настраиваются: у своей сборки клиента можно указать любые ключи, которыми она
пользуется. Клиент выбирается из списка известных сборок, из всех приложений на устройстве
или задаётся пакетом вручную.

## Сервер лаунчера (samp-launcher/server)

Раздаёт приложению список серверов, мод-паки, новости, ссылки на сборки клиента и обновления,
опрашивает SA-MP-серверы по UDP и имеет **веб-панель** для управления всем этим.

```bash
cd samp-launcher/server
node server.js              # http://0.0.0.0:8090
DEMO=1 node server.js       # с примерами (серверы, новость, сборки клиента)
```

Панель — по адресу сервера (`http://localhost:8090`), пароль по умолчанию `modar`
(хранится в `data/config.json`, меняется в разделе «Настройки»).

Переменные окружения: `PORT=8090`, `DATA_DIR=./data`, `QUERY_TIMEOUT=1500`, `MAX_UPLOAD=…`.

| Метод | Адрес | Кому | Что делает |
|---|---|---|---|
| GET | `/api/v1/ping` | приложению | версия сервера, счётчики |
| GET | `/api/v1/servers?live=1` | приложению | список серверов + живой статус (кэш 20 с) |
| GET | `/api/v1/mods` | приложению | каталог мод-паков (ссылки, размеры, SHA-256) |
| GET | `/api/v1/news` | приложению | новости |
| GET | `/api/v1/clients` | приложению | откуда скачать клиент, если его нет |
| GET | `/api/v1/launcher` | приложению | версия обновления лаунчера |
| GET | `/api/v1/admin/state` | панели | всё сразу |
| POST | `/api/v1/admin/servers`, `/mods`, `/news`, `/clients`, `/launcher` | панели | создание и правка |
| POST | `/api/v1/admin/import` | панели | импорт списка строками «ip:порт Название» |
| POST | `/api/v1/admin/query` | панели | опросить любой сервер: инфо, правила, игроки |
| POST | `/api/v1/admin/upload?kind=mod\|launcher` | панели | загрузка файла мода или APK (multipart) |
| GET | `/files/mods/*`, `/dl/*` | всем | раздача файлов с поддержкой Range |
| GET | `/` | всем | веб-панель |
| GET | `/preview` | всем | макет экранов приложения |

**Мод-пак** описывается парой полей: `kind = zip` — архив, который распаковывается в каталог игры
(`target` — подкаталог внутри него), `kind = file` — один файл, который кладётся по пути `target`.
Сервер считает SHA-256 при загрузке, приложение проверяет его перед установкой и падает с понятной
ошибкой, если файл подменили.

## Сборка APK

### Вариант 1 — без Android Studio (так собран APK в репозитории)

```bash
tools/fetch-toolchain.sh                  # один раз: aapt2, d8, apksigner, ecj, JRE
samp-launcher/tools/build-apk.sh          # → samp-launcher/apk/ModarSAMP-1.0-debug.apk
```

Полезные переменные:

```bash
API_URL=http://192.168.1.10:8090 \
GAME_DIR=/storage/emulated/0/GTA \
samp-launcher/tools/build-apk.sh          # предзаполнит адрес сервера лаунчера в приложении

RELEASE=1 KEYSTORE=my.jks KS_PASS=… KEY_ALIAS=mykey \
samp-launcher/tools/build-apk.sh          # подпись своим ключом
```

### Вариант 2 — Gradle / Android Studio

Модуль подключён как `:samp-launcher:app` (см. `settings.gradle.kts`), поэтому в Android Studio
достаточно открыть корень репозитория и выбрать конфигурацию `samp-launcher:app`.

## Установка

1. Скачайте [`apk/ModarSAMP-1.0.apk`](apk/ModarSAMP-1.0.apk) (108 КБ, SHA-256
   `8d2c24d2d4458224fcfc62eaa8468bc0e21594ff88a6a253158926d551a8f75e`).
2. Разрешите установку из неизвестных источников и откройте APK.
3. Установите клиент SA-MP (любую сборку) и выдайте **обоим** приложениям доступ к файлам —
   `Настройки → Приложения → Доступ ко всем файлам`.
4. Укажите адрес сервера лаунчера (`samp-launcher/server`) в настройках приложения —
   оттуда придут серверы, моды и новости.
5. Выберите клиент кнопкой «Выбрать установленный клиент», добавьте сервер кнопкой «+» и нажмите
   на него — лаунчер запустит клиент и передаст адрес.

Минимальная версия Android — **7.0 (API 24)**, целевая — **14 (API 34)**.
На Android 11+ приложение просит «Доступ ко всем файлам» — без него нельзя положить мод в папку игры.

## Проверка (что действительно протестировано)

```bash
samp-launcher/tools/test-query.sh          # ядро приложения против настоящего UDP
cd samp-launcher/server && npm test        # сервер: опрос, API, загрузка файлов
```

* `test-query.sh` поднимает **mock-сервер SA-MP** (`tools/mock-samp-server.js`) и прогоняет по нему
  код приложения `SampQuery.java`: 26 проверок — информация, правила, игроки с пингом, краткий список,
  измерение задержки, определение оффлайна, русское название в **Windows-1251**, SHA-256.
* `npm test` в `samp-launcher/server` — 24 проверки: опрос серверов из Node, кэш, пакет по протоколу,
  вход в панель, живой статус через mock-сервер, импорт списка, загрузка мод-пака (multipart),
  раздача файла с Range-запросами, обновление лаунчера, смена пароля, запрет обхода каталогов.

Мок-сервер полезен и вручную — с ним видно, как лаунчер ведёт себя с живым сервером:

```bash
node samp-launcher/tools/mock-samp-server.js 7777 --players 42
node samp-launcher/tools/mock-samp-server.js 7799 --cp1251 --name "Русский Мод | Сервер"
```

## Ограничения и честные замечания

* Лаунчер **не содержит самого клиента** SA-MP: он запускает уже установленную сборку. Если сборка не
  читает extras, адрес придётся вставить из буфера обмена — это ограничение чужих клиентов, а не лаунчера.
* Список известных пакетов клиента составлен по открытым сборкам (`com.gta.game`, `com.xyron.game`,
  `com.nativo.rpg`, `com.rstarx.hexrays`, `ru.unisamp_mobile.launcher` и др.). В настройках можно указать
  любой свой пакет и активити.
* Разрешение «Доступ ко всем файлам» нужно для установки модов в папку игры; приложение отказывается
  работать с модами без него и объясняет это пользователю.
* Подпись APK в репозитории — отладочный ключ (как и у остальных приложений репозитория).
