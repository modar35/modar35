Как это работает. Онлайн и правила лаунчер получает сам — по настоящему протоколу SA-MP Query (UDP, коды i, r, c, d, p), без посредников. Адрес сервера передаётся установленному клиенту через Intent (extras ip, port, nickname, password и строка аргументов), а если сборка их не читает — адрес остаётся в буфере обмена для вставки в меню игры.

Список серверов, мод-паки и новости раздаёт ваш сервер лаунчера (samp-launcher/server, Node.js без зависимостей). Его веб-панель — по адресу этого сервера, пара «программа + панель» показана в разделе samp-launcher/README.md.
