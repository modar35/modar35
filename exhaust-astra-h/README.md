# Выхлопная трасса (раздвоенная) — Opel Astra H 1.8 Caravan (универсал, G09)

Параметрический генератор: 3D-модель + чертёж + раскрой под гибку + расчёт потока/звука/зазоров.
В расчёте мотор Z18XER (140 л.с.), но считается и Z18XE (125 л.с.), и дефорс 85 кВт.

## Как запустить

```bash
python3 -m venv .venv-exh && .venv-exh/bin/pip install numpy matplotlib trimesh ezdxf scipy
.venv-exh/bin/python gen_exhaust.py --preset tour --engine Z18XER --out out
```

Ключи (`--help`): `--preset tour|sport|stockish` · `--engine Z18XE|Z18XER|Z18XER_85` ·
`--tips both|left` (вразножку / обе насадки слева) · `--tip-in-bumper` · `--mandrel 1.3…2.2` ·
`--box-bottom` · `--box-x` · `--box-y` · `--tip-angle` · `--z-line` · `--oem-outlet X Y Z`
(замеренная точка среза стока — самая важная правка под конкретную машину).

## Что где лежит

| путь | что это |
|---|---|
| `gen_exhaust.py` | весь генератор: компоновка, гидравлика, акустика, экспорт |
| `out/` | **базовый вариант `tour`** — полный комплект, включая 3D |
| `out/3d/` | STL по деталям + сборка + `astra_h_dual_exhaust.glb` (Blender/FreeCAD/viewgltf) |
| `out/dxf/` | чертёж 1:1, вид сбоку + сверху, размеры, таблица раскроя |
| `out/scad/` | OpenSCAD: правка OD/углов текстом → F6 → STL (STEP через FreeCAD) |
| `out/png/` | `render_3d_iso.png` (2 ракурса), `drawing_side_top.png`, `bends.png`, `clearances.png` |
| `out/*.csv`, `spec.json`, `README.md` | раскрой, карта гибов, BOM, всё числами, записка технологу |
| `out_sport/` `out_stockish/` `out_lefttips/` `out_tight/` | те же отчёты для остальных вариантов (меш-файлы не лежат в репо — пересоздаются командой выше) |
| `out_all/СРАВНЕНИЕ-ВАРИАНТОВ.md` | сводная таблица: масса, ΔP, гул, углы, замечания |

## Архитектура базового варианта

Приёмная от штатного шарового **после катализатора и 2-го лямбда-зонда** (кат, гофра, датчики — сток) →
Ø60.5×1.5 по тоннелю на высоте Z=330 → резонатор Ø127×420 → true-Y Ø60→2×Ø51 на x=1900 → две ножки
по 1020 мм (равные, по одному гибу 22.5°) → две овальные банки 420×250×150 (по 10.1 л, сердечник Ø45,
2 перегородки, набивка) за задней осью → хвосты Ø51 → 2×Ø76 из-под бампера, y=±577. 8 подвесов,
ни одного жёсткого крепления.

Итог: развёртка 4.92 м, 6 гибов, **20.6 кг**, противодавление **6.71 кПа (0.97 psi)** на отсечке,
0 совпадений резонанса хвоста с гармониками, зазоры: до дороги 255, под баком 50, до торсиона 37,
до пола 115 мм, угол съезда 14.6°.

## Дисциплина безопасности

Кат и оба лямбда-зонда не трогать. Зазоры до бака/тормозной трубки/проводки — из `out/png/clearances.png`,
но перед резкой их проверяют замером на конкретной машине: пружины, ГБО, фаркоп, «не родной» даунпайп
и ремонт после ДТП меняют всё. Сварка над баком = снять минус, экран, огнетушитель.
