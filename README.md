# Modar AI — ИИ-ассистент для Android

Нативное Android-приложение (Java + Android framework, **без AndroidX и без единой сторонней
библиотеки**) — чат с современными ИИ-моделями, в том числе с **GPT-6** (`gpt-6-astra`).

Приложение работает с любым **OpenAI-совместимым** API: официальный OpenAI, OpenRouter, Groq,
Together, локальные серверы (Ollama, LM Studio, llama.cpp) — адрес, ключ и название модели
задаются в настройках.

---

## Возможности

| Раздел | Что умеет |
|---|---|
| 💬 Чат | Несколько диалогов, лента сообщений «пузырями», автоназвания по первому вопросу |
| ⚡ Потоковый ответ | Печать ответа по мере генерации (SSE), кнопка «Стоп» |
| 🎙 Голос | Голосовой ввод через системное распознавание речи + озвучка ответов (TTS) |
| 🖼 Картинки | Отправка изображения модели (multimodal, кодируется в `image_url` data-URI) |
| ✍️ Markdown | Заголовки, списки, **жирный**, *курсив*, `код`, блоки кода, цитаты, ссылки |
| 🗂 Диалоги | Список бесед, переименование, очистка, удаление, локальная история |
| ⚙️ Настройки | API-ключ, Base URL, модель (+ загрузка списка моделей с сервера), системный промпт, температура, лимит токенов, язык речи, проверка соединения |
| 🔒 Приватность | Ключ хранится только на устройстве, запросы идут напрямую в выбранный сервис, нет рекламы и аналитики |

Интерфейс: тёмная тема, Material, адаптивная иконка. Размер APK — около **70 КБ**.

## Установка

1. Скачайте готовый файл: [`apk/ModarAI-1.0.apk`](apk/ModarAI-1.0.apk)
   (он же приложен к релизу **v1.0.0**; SHA-256:
   `a2136b52a53693318d6c4957b84f6b2e14f13cb803a786bac5f0d94d5b55cf16`).
2. На телефоне разрешите установку из неизвестных источников для файлового менеджера/браузера.
3. Откройте APK → «Установить».
4. При первом запуске приложение попросит ввести ключ API.

Минимальная версия Android — **7.0 (API 24)**, целевая — **14 (API 34)**.

Предпросмотр интерфейса без установки — [`docs/preview.html`](docs/preview.html)
(откройте файл в браузере).

## Первый запуск

1. **⚙️ Настройки** → вставьте API-ключ.
2. Проверьте **Base URL** (по умолчанию `https://api.openai.com/v1`).
3. Выберите модель: поле «Модель» → кнопка **«Выбрать»** → пресеты или
   «⤓ Загрузить список с сервера…» (приложение само спросит `/models` у сервера).
4. Нажмите **«Проверить соединение»** — приложение покажет, сколько моделей видит сервер.
5. **Сохранить** → задайте вопрос текстом, голосом (🎙) или приложите картинку (🖼).

### Модели

По умолчанию выбрана `gpt-6-astra` (GPT-6 Astra). Название модели можно изменить на любое,
которое поддерживает ваш сервис: `gpt-5.6`, `gpt-4o`, `o3`, `anthropic/claude-sonnet-4.5`
(OpenRouter), `llama3.1` (Ollama) и т.д.

### Локальные модели

Если модель запущена на компьютере:

* Base URL: `http://192.168.1.50:11434/v1` (Ollama) — именно IP компьютера, не `localhost`,
  потому что `localhost` на телефоне — это сам телефон;
* ключ можно оставить любым непустым (`ollama`);
* приложение уже разрешает открытые HTTP-соединения (`usesCleartextTraffic`).

## Сборка

### Вариант 1 — Android Studio / Gradle (обычный путь)

```bash
# откройте папку проекта в Android Studio и нажмите Run
# либо из консоли:
gradle :app:assembleDebug     # нужен Android SDK (compileSdk 34) и JDK 17+
```

Gradle-файлы (`settings.gradle.kts`, `build.gradle.kts`, `app/build.gradle.kts`) лежат в репозитории.
Отдельной Gradle-обёртки нет: `gradle wrapper --gradle-version 8.7` создаст её при необходимости.

### Вариант 2 — без Android Studio и без Gradle

В репозитории есть полностью автономная сборка: `aapt2 → ecj → d8 → zipalign → apksigner`.

```bash
tools/fetch-toolchain.sh     # один раз скачивает и распаковывает инструменты в ~/.cache/tc
tools/build-apk.sh           # собирает подписанный APK в dist/
```

Тулчейн тянется из публичных пакетов (PyPI: `jdk4py`; npm: `aaptjs3`,
`@drxiaozhi/minapk`) — Android SDK и Gradle не нужны.

Сборка своим ключом (для публикации):

```bash
RELEASE=1 KEYSTORE=/путь/my-release.jks KS_PASS=пароль KEY_ALIAS=mykey \
  tools/build-apk.sh
```

Создать ключ:

```bash
keytool -genkeypair -v -keystore my-release.jks -alias mykey \
  -keyalg RSA -keysize 2048 -validity 10000
```

## Структура проекта

```
app/src/main/AndroidManifest.xml         манифест (интернет, микрофон, 3 активити)
app/src/main/java/com/modar/ai/
    MainActivity.java                    экран чата: потоковый ответ, вложения, «Стоп»
    ChatsActivity.java                   список диалогов (открыть/переименовать/удалить)
    SettingsActivity.java                настройки, список моделей, проверка соединения
    OpenAiClient.java                    клиент /chat/completions: SSE, картинки, ошибки
    Markdown.java                        Markdown → Spannable (заголовки, код, ссылки)
    VoiceInput.java                      распознавание речи
    Tts.java                             озвучка ответов
    ChatAdapter.java / Ui.java           лента сообщений и мелкие помощники
    Store.java / Conversation.java / Message.java   локальная история диалогов
    Prefs.java                           настройки (SharedPreferences)
app/src/main/res/                        тема, цвета, иконки-векторы, макеты
tools/build-apk.sh                       сборка APK без Gradle
tools/zipalign.py                        выравнивание несжатых записей APK
tools/fetch-toolchain.sh                 загрузка тулчейна
```

Хранение данных: `SharedPreferences` (настройки и история в JSON) + внутренний каталог
`files/images` для вложений. Никаких серверов-посредников: запрос уходит напрямую
по указанному вами адресу.

## Безопасность и приватность

* API-ключ хранится в приватном хранилище приложения (`SharedPreferences`) и не передаётся
  никуда, кроме адреса, который вы указали в настройках.
* Приложение не содержит рекламных SDK, аналитики и трекеров.
* Разрешения: `INTERNET` (запросы к модели) и `RECORD_AUDIO` (только голосовой ввод, спрашивается
  в момент нажатия на микрофон).
* Открытые HTTP-соединения разрешены — это нужно для локальных моделей. Если пользуетесь
  только облаком, можно убрать `android:usesCleartextTraffic="true"` из манифеста.

## Ограничения текущей версии

* Нет стриминга аудио в реальном времени (голос — системные распознавание/синтез, а не Realtime API).
* Нет синхронизации диалогов между устройствами (история только локальная).
* Подпись в релизе — отладочный ключ; для публикации в Google Play соберите своим ключом
  (см. «Сборка»).
