# Грузовичок — доставка грузов

Android-приложение и браузерный предпросмотр для сервиса перевозок: клиент размещает заявку, а водители на газелях и грузовых автомобилях находят подходящие заказы.

## Что уже работает в прототипе

- лента свежих заказов с маршрутом, грузом, временем, типом кузова и стоимостью;
- фильтр по типу кузова;
- кнопка «Взять заказ»;
- создание новой заявки с маршрутом и описанием груза;
- разделы «Мои рейсы» и «Профиль»;
- адаптивная браузерная версия в [`docs/preview.html`](docs/preview.html);
- нативный Android UI без сторонних библиотек.

## Запуск браузерной версии

Откройте `docs/preview.html` в браузере. Она адаптирована под экран телефона, но удобно смотрится и на компьютере.

## Android

Исходники находятся в `app/src/main`. Минимальная версия Android — API 24, целевая — API 34. Проект собирается обычным Gradle/Android Studio:

```bash
gradle :app:assembleDebug
```

Готовый APK из исходного прототипа лежит в `apk/ModarAI-1.0.apk`; после сборки используйте APK из `app/build/outputs/apk/debug/`.

## Следующий этап продукта

Для запуска в продакшн потребуются сервер и авторизация, карта с геокодированием, чат клиента с водителем, статусы заказа, push-уведомления, онлайн-оплата и проверка документов водителя.
