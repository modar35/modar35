# Сумеречный разлом — Android 3D MOBA

Оригинальный прототип MOBA: полноэкранная изометрическая 3D-арена, три выбираемых героя, волны бойцов, башни, ядра баз и нейтральный лесной кристалл. Проверенная версия 0.2.0 запускается в браузере и в Android WebView-приложении; отдельный экспериментальный Unity-порт находится в `unity/RiftArenaUnity` и пока не имеет собранного или проверенного APK.

> Версия 0.2.0 остаётся одиночной тренировкой на одной линии против ИИ — это не онлайн-матчи 5 на 5. В ней есть локальный профиль и черновой API для синхронизации аккаунта, но для онлайн-входа из APK нужно разместить API на постоянном HTTPS-сервере. Игра использует оригинальных персонажей и облики, а не копирует героев или графику Mobile Legends.

## Что уже можно сделать в игре

- Перемещать героя по 3D-арене с виртуальным джойстиком, стрелками или кликом мыши.
- Атаковать ближайшие цели и использовать четыре способности: **Q** — осколок, **W** — рывок, **E** — сфера, **R** — массовый удар.
- Сражаться с героем ИИ и волнами бойцов; башни защищают ядра баз.
- Зарабатывать золото, выпить одно зелье восстановления, погибнуть и возродиться.
- Разрушить вражескую башню, открыть путь к ядру и завершить матч.
- Поставить матч на паузу, начать заново или вернуться в меню.
- Выбрать одного из трёх оригинальных героев: мага Эларис, убийцу Раэна или стража Варкора; у героев разные характеристики и комплекты Q/W/E/R.
- Открыть два цветовых облика для каждого героя; заработать опыт, повышать уровень в матче и победить нейтрального хранителя кристалла ради золота и временного усиления атаки.
- Настроить качество графики, синтезированную фоновую музыку и эффекты; включить голосовые реплики героя через системный русский TTS, если WebView устройства его поддерживает.
- Смотреть матчи, победы, K/D/A и медали в личном кабинете. Без сервера прогресс сохраняется локально; после подключения API профиль синхронизируется через аккаунт.

Карта и процедурные модели собраны из оригинальных 3D-примитивов и текстур. В APK встроен Three.js 0.149.0 (лицензия MIT находится в `web/vendor/THREE-LICENSE.txt`); CDN и сторонние графические ассеты не используются.

## Запустить предпросмотр

```bash
python3 web/server.py
```

Затем откройте `http://localhost:8080`. На мобильном устройстве удобно повернуть экран горизонтально. В Arena-предпросмотре страница также доступна через live preview запущенного веб-сервера.

### Профиль и API аккаунтов

Веб-сервер дополнительно поднимает прототип API профилей на SQLite:

- `POST /api/register`, `POST /api/login`, `POST /api/logout`
- `GET /api/profile`, `POST /api/match`, `GET /api/health`

Пароли хешируются PBKDF2-HMAC-SHA256; сессии — случайные bearer-токены с ограниченным сроком. База по умолчанию создаётся в `runtime/riftarena.sqlite3` (этот каталог исключён из Git); путь можно изменить через `RIFT_DB_PATH`. В браузере игра обращается к API того же origin. В установленном APK откройте **Настройки → HTTPS-адрес сервера профиля** и укажите постоянный адрес размещённого API.

Это демонстрационная backend-реализация: нет подтверждения почты, сброса пароля, боевого аудита результатов или внешнего matchmaking. Перед публичным запуском разместите API за HTTPS reverse proxy, добавьте резервные копии и production-защиту от злоупотреблений. Играть в тренировку можно без аккаунта и без подключения к сети.

## Управление

| Действие | Android / сенсор | Браузер / ПК |
|---|---|---|
| Движение | Виртуальный джойстик | Клик по земле или стрелки |
| Обычная атака | Удерживать кнопку «Атака» | Удерживать `Space` |
| Способности | Кнопки `Q`, `W`, `E`, `R` на HUD | Клавиши `Q`, `W`, `E`, `R` |
| Зелье | Кнопка с флаконом | Клавиша `1` |
| Пауза | Кнопка `Ⅱ` | `Esc` |

На Android управление рассчитано на горизонтальную ориентацию. В браузерной версии при вертикальном игровом экране появляется подсказка повернуть устройство.

## Установить Android APK

Скачайте [`apk/RiftArena-0.2.0.apk`](apk/RiftArena-0.2.0.apk) (debug-подпись; SHA-256: `8e7e1046375d8478f743155df5054db81489d83f155e5efcb863318693c49184`). Скопируйте APK на Android 7.0 или новее, разрешите установку для используемого файлового менеджера и откройте файл. Нужна поддержка OpenGL ES 2.0/WebGL в Android System WebView.

Игра и матч работают офлайн; разрешение Android INTERNET используется только для добровольной синхронизации аккаунта с настроенным HTTPS-сервером.

## Собрать APK

### Без Android Studio

```bash
tools/fetch-toolchain.sh   # один раз: загрузить инструменты сборки в ~/.cache/tc
tools/build-apk.sh         # dist/RiftArena-0.2.0-debug.apk
```

Скрипт `tools/build-apk.sh` включает файлы из `web/` в APK и подписывает отладочным ключом. Для собственного release-ключа:

```bash
RELEASE=1 KEYSTORE=/path/to/release.jks KS_PASS='пароль' \
  KEY_ALIAS='имя-алиаса' tools/build-apk.sh
```

### Через Gradle

Откройте проект в Android Studio или выполните:

```bash
gradle :app:assembleDebug
```

Gradle должен быть доступен в системе; проект использует Android Gradle Plugin 8.5.2, compileSdk 34 и JDK 17+. APK появится в `app/build/outputs/apk/debug/`.

## Экспериментальный Unity-порт

Начат отдельный перенос игрового вертикального среза в `unity/RiftArenaUnity`: там есть исходники процедурной 3D-арены, трёх героев, ИИ и волн, сенсорного HUD, настроек, локального профиля и HTTPS-клиента. Это всё ещё одиночная тренировка, а не сетевые матчи 5 на 5. Проект и сборка Android пока не проверялись в Unity Editor: он отсутствует в текущей среде, поэтому Unity APK ещё нет. Проверенный APK `0.2.0` остаётся прежней Android WebView-версией.

Для открытия нужен Unity 2022.3 LTS с Android Build Support, SDK/NDK и OpenJDK. Из корня репозитория APK собирается командой:

```bash
UNITY_EDITOR=/path/to/Unity tools/build-unity-android.sh
```

Подробности и ограничения описаны в [`unity/RiftArenaUnity/README.md`](unity/RiftArenaUnity/README.md). Аккаунты в Unity-клиенте требуют постоянного HTTPS-размещения API; локальный `web/server.py` сам по себе не является хостингом.

```text
app/src/main/AndroidManifest.xml       Android: landscape, fullscreen, WebGL
app/src/main/java/com/modar/riftarena/
  MainActivity.java                    нативная WebView-оболочка и кнопка Back
web/                                   общий набор игровых assets для Gradle/APK и предпросмотра
  index.html                           меню, HUD и экран матча
  styles.css                           адаптивный интерфейс и touch controls
  meta.js                              герои, профиль, медали, настройки и API-клиент
  app.js                               Three.js-сцена, волны, ИИ, опыт и лесной объект
  vendor/three.min.js                  локальный 3D-движок
  server.py                            предпросмотр + SQLite API профилей

tools/build-apk.sh                     автономная сборка текущей WebView-версии APK
tools/build-unity-android.sh            batchmode-сборка экспериментального Unity APK
tools/fetch-toolchain.sh               загрузка Android-тулчейна для Gradle
unity/RiftArenaUnity/                  исходники незавершённого Unity-переноса
docs/preview.html                      страница быстрого перехода к игре
```
