# Сумеречный разлом — экспериментальный Unity-порт

Unity-вертикальный срез одиночной тренировки на одной линии против ИИ. Это исходники прототипа, не готовый сетевой клиент и не опубликованный APK. Текущий проверенный Android APK в корне репозитория — веб-версия 0.2.0.

## Уже перенесено в исходники

- Три оригинальных героя с разными ролями, базовыми параметрами и комплектами Q/W/E/R; два цветовых варианта на героя.
- Процедурная 3D-арена: диагональная линия, река и переход, лес, нейтральный храм, башни и ядра.
- Управление героем, противник-ИИ, волны бойцов, атакующие башни, опыт/уровни, золото, зелье и временный бафф нейтрального кристалла.
- Победа после разрушения вражеского ядра, экран результата и локальная статистика/медали.
- Сенсорный джойстик, кнопки атаки/умений, мини-карта, пауза, экран загрузки и выбор облика.
- Настройки качества, музыки/эффектов и голосовых реплик. Музыка и звуковые эффекты синтезируются без внешних ассетов; на Android голосовые фразы проходят через системный русский TTS и разный pitch героев.
- Клиент HTTPS API для регистрации, входа, профиля и отправки результата. URL постоянного API указывается в настройках приложения.

Все модели и материалы пока процедурные, собраны из примитивов Unity; авторских анимаций и записанной озвучки ещё нет. Это однопользовательский вертикальный срез, не матчи 5 на 5.

## Открыть в Unity

1. Используйте **Unity 2022.3 LTS** с модулями **Android Build Support**, **Android SDK & NDK Tools** и **OpenJDK**.
2. Откройте папку `unity/RiftArenaUnity` как Unity-проект. Unity Package Manager загрузит пакет `com.unity.ugui`.
3. При первом открытии Editor-скрипт создаст пустую boot-сцену `Assets/Scenes/RiftArenaMain.unity` и добавит её в Build Settings. Runtime bootstrap сам создаёт карту, UI и игровой цикл при запуске.
4. Нажмите Play в Editor либо откройте меню **Rift Arena → Build Android APK**.

Управление в Editor: стрелки — движение, `Space` — обычная атака, `Q/W/E/R` — способности, `1` — зелье, `Esc` — пауза. На Android используется экранный джойстик и кнопки.

## Android APK

Из корня репозитория:

```bash
UNITY_EDITOR=/path/to/Unity tools/build-unity-android.sh
```

Если `Unity` уже в `PATH`, переменную задавать не нужно. Скрипт запускает batchmode build и пишет результат в `dist/RiftArena-Unity-0.3.0.apk`; лог Unity — в `dist/unity-android-build.log`. Требуется рабочая лицензия Unity и Android-модуль с IL2CPP. APK в `dist/` игнорируется Git.

Unity Editor в среде, где начат этот перенос, отсутствует. Поэтому сборка Android из Unity, запуск сцены в Editor и проверка на физическом устройстве **ещё не выполнены**. До такой проверки проект следует считать незавершённым прототипом.

## Профиль и онлайн

Профиль без входа хранится в `PlayerPrefs`. Для настоящей регистрации и синхронизации в приложении откройте **Профиль** и **Настройки → HTTPS-адрес сервера профиля**. Unity-клиент использует те же JSON-маршруты (`/api/register`, `/api/login`, `/api/logout`, `/api/profile`, `/api/match`), что и `web/server.py`.

`web/server.py` — локальный демонстрационный SQLite backend, а не постоянный публичный сервис. Для реального онлайн-аккаунта его ещё нужно развернуть на собственном постоянном сервере за HTTPS reverse proxy и обслуживать с резервными копиями. До размещения API сетевой вход из APK не подключён; матч всегда можно сыграть офлайн.
